## 核心能力

- **收银自动算价**：等级折扣、营销活动、积分抵现自动叠加，250ms 实时报价
- **卡项闭环**：储值卡、次卡、年卡，一键购卡、收银自动抵扣、到期自动校验
- **会员经营**：等级自动升级、积分抵现规则可配置、余额不足/卡到期/沉睡会员自动提醒
- **营销活动**：折扣、满减、新客礼、生日礼，按服务项目定向，收银自动参与
- **经营报表**：营收趋势、热门项目、技师业绩、会员增长、支付占比
